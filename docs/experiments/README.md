# Experiments and evidence

- [Clip-selection history](clip-selection.md): observations, interpretations,
  limitations and next experiments from the project discussion.
- [Prompt/model progression](prompt-history.md): historical variants and a current
  reproducible snapshot. Historical versions are not all preserved verbatim.
- [Run template](run-template.md): copy for the next controlled comparison.
- [Project evolution](../project-history.md): architecture, debugging, workflow,
  manual export and implementation status.

Raw logs and full prompts/transcripts belong in ignored `diagnostics/`. Keep
sanitized conclusions here. Experiment records are not benchmarks unless inputs,
configuration and evaluation were controlled and recorded.
